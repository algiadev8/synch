要**与他人共享 Obsidian vault**，可以使用 Obsidian Sync、Synch、私有 Git 仓库或云端共享文件夹。每个人在 Obsidian 中打开本地副本，再通过选定的方式在副本之间传递更改。把 vault 文件夹发给别人，只是提供当时的一份副本，并不会让之后的笔记持续同步。

无论是学习小组、共享研究资料库还是团队知识库，都应先确定成员如何加入，以及使用哪些设备。本文介绍四种协作方法，包括 Obsidian Sync 和 Synch 的设置步骤，以及存储空间、加密访问和版本历史的比较。

![三台笔记本电脑连接到一组相互链接的共享笔记，代表各设备上的 Obsidian vault 本地副本。](./shared-vault-collaboration.webp)

## 应该选择哪种 Obsidian 共享方式？

| 方法 | 适用情况 | 主要要求或限制 |
|---|---|---|
| **Obsidian Sync** | 希望使用官方集成功能，或所有人都已订阅 | 每位协作者都需要 Sync 订阅 |
| **Synch Plus** | 两三个人希望共用一份团体订阅 | 成员需加入组织并完成加密访问审批 |
| **私有 Git 仓库** | 所有人都熟悉版本控制 | 协作者需管理提交、拉取、推送和合并冲突 |
| **云端共享文件夹** | 存储服务支持在所有成员的设备上提供本地共享文件夹 | 移动端访问和冲突处理因服务商而异 |

如果只是**分享 Obsidian 笔记供他人阅读**，发送 Markdown 文件或导出 PDF 即可。

**共享 vault 不等于实时协同编辑。** 同步会在本地副本之间传递已保存的更改，并不一定显示他人的光标或每一次按键。处理同一篇笔记时，请协调编辑安排。

## 如何与他人共享 Obsidian vault

先备份 vault，再从下面选择一种方法。新建小组时，使用专用 vault 可以把个人笔记与所有人都能访问的资料分开。

### 1. 使用 Obsidian Sync 共享 vault

首先准备一个已连接到 Obsidian Sync 远程 vault 的本地 vault。每位协作者都需要有效的 Sync 订阅。

邀请步骤如下，菜单名称以英文界面为准：

1. 打开 **Settings → Sync**。
2. 选择 **Remote vault** 旁边的 **Manage**。
3. 找到要共享的 vault，选择 **Manage sharing**。
4. 在 **Invite user** 下输入对方的电子邮箱地址。
5. 选择 **Add**。

受邀者随后将本地 vault 连接到共享的远程 vault。如果 vault 使用端到端加密，请通过可信渠道向对方提供加密密码。详情参见[官方共享 vault 指南](https://obsidian.md/help/sync/collaborate)。

协作者可以编辑 vault 内容，但只有所有者能邀请更多人。Obsidian Sync 不提供细粒度权限或实时协同编辑。

### 2. 使用 Synch 共享 vault

确保 vault 已连接到 Synch，且组织使用 Plus 套餐，然后执行以下步骤：

1. **邀请协作者。** 打开 **Vault 共享 → 管理组织**，发送电子邮件邀请。
2. **请对方申请访问。** 接受邀请后，对方打开一个空的 Obsidian vault，登录 Synch，再从 **连接 vault → 与我共享** 中选择你的 vault。
3. **批准并连接。** 通过另一个可信渠道核对对方的完整访问码，然后在 **Vault 共享** 中批准。对方回到发起请求的设备，设置自己的 vault 密码并完成连接。

批准访问也会授予对保留历史的访问权限。受邀成员需要 Synch 账号，但不需要另外购买付费套餐。

### 3. 使用 Git 共享 Obsidian vault

私有 Git 仓库适合已经在使用版本控制的小组。典型流程如下：

1. 创建私有仓库，只添加想要共享的 vault 内容。上传前请检查附件、配置文件以及已有的 Git 历史。
2. 邀请协作者加入仓库。
3. 每个人克隆仓库，并在 Obsidian 中将本地文件夹作为 vault 打开。
4. 编辑前先拉取最新更改，完成后提交并推送。如有冲突，先解决再继续。

[Obsidian Git 插件](https://github.com/Vinzent03/obsidian-git/blob/master/docs/Start%20here.md)可以让你在 Obsidian 内操作 Git。私有仓库会限制访问，但本身不提供端到端加密。如果你刚接触 Git，可以阅读我们的 [Obsidian Git 同步指南](/zh-cn/blog/obsidian-git-sync/)，了解工作流程及其取舍。

### 4. 通过云端文件夹共享 vault

只要服务商能让每位协作者在本地访问同一组文件，就可以考虑共享文件夹：

1. 在云存储中创建专用的 vault 文件夹，并授予协作者编辑权限。
2. 所有人将文件夹同步到自己的设备，并保持文件已下载到本地。
3. 在 Obsidian 中将本地文件夹作为 vault 打开。
4. 添加更多资料前，先测试笔记和附件的更改能否双向同步。

请先检查移动端支持。在两台笔记本电脑上可用的共享文件夹，在手机上的 Obsidian 中可能无法访问。[Obsidian 同步方法指南](https://obsidian.md/help/sync-notes)说明了各平台的限制。为此 vault 只使用一个同步服务，避免更新互相冲突。

## 共享 vault：Obsidian Sync Plus 与 Synch Plus 对比

Obsidian Sync 是 Obsidian 内置的官方服务。Synch 通过社区插件连接，并在 Plus 套餐中提供基于组织的共享。两者都支持对 vault 内容进行端到端加密。按功能比较，Obsidian Sync Plus 与 Synch Plus 更接近：两者都提供一年的版本历史，并支持比 Obsidian Standard 更大的附件。不过，它们的存储配额和订阅方式仍有区别。

| 项目 | Obsidian Sync Plus | Synch Plus |
|---|---|---|
| **订阅方式** | 每位协作者都需要有效的 Sync 订阅 | **一份订阅最多包含 3 名成员，包括所有者** |
| **端到端加密** | 可用于加密 vault | 包含 vault 内容加密 |
| **vault 密码设置** | 协作者输入 vault 的加密密码 | **获批后，每位成员设置自己的 vault 密码** |
| **加入方式** | 所有者通过 Sync 设置邀请 | 先接受组织邀请，再完成加密访问审批 |
| **版本历史** | 12 个月 | 1 年 |
| **包含的存储空间** | 一个账号下的所有 vault 合计 10 GB | **每个 vault 5 GB，3 个共 15 GB** |
| **最大文件大小** | 200 MB | 100 MB |
| **同步 vault 数量** | 每个账号 10 个 | 每个组织 3 个 |

有关要求和最新限制，请参阅 [Obsidian 共享 vault 指南](https://obsidian.md/help/sync/collaborate)、[Obsidian Sync 套餐](https://obsidian.md/sync)和 [Synch 定价](https://synch.run/zh-cn/pricing)。

### 加密访问：共用密码还是个人密码

使用 Synch 时，**无需把自己的 vault 密码发给对方，也能邀请对方加入**。管理员通过协作者的验证码批准访问，因此不需要向整个小组分发共用密码。

## 为日常协作整理共享 vault

无论选择哪种方法，事先约定一些规则都会有帮助。

**将个人笔记与共享资料分开。** 专用的协作 vault 能明确哪些内容属于小组。只放入你打算让他人访问的资料，并考虑保留的历史中是否包含私人内容。

**保持结构简单。** 一篇入口笔记、一个项目文件夹、会议记录和参考资料通常就够了。说明新笔记应该放在哪里，让成员无需重新整理整个 vault 就能参与。

**协调多人频繁编辑的笔记。** 开会时指定一名记录者，或为长文档分配不同章节。在把工作交给别人之前，等待同步完成。实用的编辑习惯可参考[预防 Obsidian 同步冲突指南](/zh-cn/blog/obsidian-sync-conflicts/)。

**将设置与内容分开考虑。** 即使笔记是共享的，主题、快捷键和工作区偏好也可能因人而异。请检查所选方法如何处理 `.obsidian` 配置文件夹。

**一个 vault 只使用一种同步方式，并另行备份。** Obsidian 不建议在同一 vault 上混用同步服务，因为可能引发冲突。[同步指南](https://obsidian.md/help/sync-notes)说明了相关注意事项。

## Obsidian vault 共享常见问题

### 可以免费共享 Obsidian vault 吗？

使用 Git 或已有的共享存储套餐，可能无需专门订阅同步服务就能协作。请检查托管限制、设备兼容性以及每个人需要完成的设置。免费软件也可能需要持续维护。

### 可以直接把 vault 文件夹发给别人吗？

可以，前提是对方需要的只是某个时间点的副本。请包含笔记所依赖的附件，并先移除私人资料。如果不设置同步或其他协作流程，之后的编辑不会在两份副本之间传递。

### 不使用 Obsidian Sync 也能共享 vault 吗？

可以。你可以使用 Synch、Git 或兼容的云端共享文件夹，无需支付 Obsidian Sync 订阅费。如果选择官方共享 vault 服务，每位协作者都需要有效的 Obsidian Sync 订阅。

### 可以只共享 vault 中的一个文件夹吗？

如需共同编辑，请创建一个独立的 vault，放入小组需要的笔记和附件。复制后检查链接：指向个人 vault 中某篇笔记的链接，并不会让协作者获得该笔记的访问权限。

### 必须共享加密密码吗？

取决于服务。使用官方 Obsidian Sync 时，协作者连接加密 vault 需要输入 vault 的加密密码。使用 Synch 时，每位协作者在加密访问获批后设置自己的 vault 密码。

### 两个人能同时编辑同一篇笔记吗？

两人可以编辑各自的本地副本，但重叠的更改可能造成冲突。不要默认本文介绍的共享方法支持实时协同编辑。如果同时写作是核心需求，请评估明确支持该功能的工具。

### 有人退出小组时该怎么办？

通过所用服务移除对方的访问权限。撤销权限不会删除已经下载的文件，因此只应共享你愿意让对方保留副本的资料。

## 哪种服务适合你的小组？

如果所有人都已订阅，或者你更喜欢官方集成功能，Obsidian Sync 是自然的选择。

如果是两三个人一起共享笔记，并希望由一个人管理套餐、邀请其他成员，可以选择 [Synch Plus](/zh-cn/pricing/)。

先用几篇互相链接的笔记和一个附件试用所选方法。迁移共享项目之前，让所有人连接、做些修改，并在实际使用的设备上检查结果。

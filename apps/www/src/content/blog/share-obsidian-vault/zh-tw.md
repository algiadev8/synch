要**與他人共用 Obsidian vault**，可以使用 Obsidian Sync、Synch、私人 Git 儲存庫或雲端共用資料夾。每個人在 Obsidian 中開啟本機副本，再透過選定的方式在副本之間傳遞變更。把 vault 資料夾傳給別人，只是提供當時的一份副本，並不會讓之後的筆記持續同步。

無論是讀書會、共用研究資料庫還是團隊知識庫，都應先確定成員如何加入，以及使用哪些裝置。本文介紹四種協作方法，包括 Obsidian Sync 和 Synch 的設定步驟，以及儲存空間、加密存取和版本歷史的比較。

![三台筆記型電腦連接到一組互相連結的共用筆記，代表各裝置上的 Obsidian vault 本機副本。](./shared-vault-collaboration.webp)

## 應該選擇哪種 Obsidian 共用方式？

| 方法 | 適用情況 | 主要要求或限制 |
|---|---|---|
| **Obsidian Sync** | 希望使用官方整合功能，或所有人都已訂閱 | 每位協作者都需要 Sync 訂閱 |
| **Synch Plus** | 兩三個人希望共用一份團體訂閱 | 成員需加入組織並完成加密存取核准 |
| **私人 Git 儲存庫** | 所有人都熟悉版本控制 | 協作者需管理提交、拉取、推送和合併衝突 |
| **雲端共用資料夾** | 儲存服務支援在所有成員的裝置上提供本機共用資料夾 | 行動裝置存取和衝突處理因服務商而異 |

如果只是**分享 Obsidian 筆記供他人閱讀**，傳送 Markdown 檔案或匯出 PDF 即可。

**共用 vault 不等於即時協同編輯。** 同步會在本機副本之間傳遞已儲存的變更，並不一定顯示他人的游標或每一次按鍵。處理同一篇筆記時，請協調編輯安排。

## 如何與他人共用 Obsidian vault

先備份 vault，再從下面選擇一種方法。建立新群組時，使用專用 vault 可以把個人筆記與所有人都能存取的資料分開。

### 1. 使用 Obsidian Sync 共用 vault

首先準備一個已連接到 Obsidian Sync 遠端 vault 的本機 vault。每位協作者都需要有效的 Sync 訂閱。

邀請步驟如下，選單名稱以英文介面為準：

1. 開啟 **Settings → Sync**。
2. 選擇 **Remote vault** 旁邊的 **Manage**。
3. 找到要共用的 vault，選擇 **Manage sharing**。
4. 在 **Invite user** 下輸入對方的電子郵件地址。
5. 選擇 **Add**。

受邀者接著將本機 vault 連接到共用的遠端 vault。如果 vault 使用端到端加密，請透過可信管道向對方提供加密密碼。詳情請參閱[官方共用 vault 指南](https://obsidian.md/help/sync/collaborate)。

協作者可以編輯 vault 內容，但只有擁有者能邀請更多人。Obsidian Sync 不提供細部權限設定或即時協同編輯。

### 2. 使用 Synch 共用 vault

確認 vault 已連接到 Synch，且組織使用 Plus 方案，接著執行以下步驟：

1. **邀請協作者。** 開啟 **Vault 共享 → 管理組織**，寄送電子郵件邀請。
2. **請對方申請存取。** 接受邀請後，對方開啟一個空的 Obsidian vault，登入 Synch，再從 **連接 vault → 與我共用** 中選擇你的 vault。
3. **核准並連接。** 透過另一個可信管道核對對方的完整存取碼，然後在 **Vault 共享** 中核准。對方回到提出請求的裝置，設定自己的 vault 密碼並完成連接。

核准存取也會授予保留歷史的存取權限。受邀成員需要 Synch 帳號，但不需要另外購買付費方案。

### 3. 使用 Git 共用 Obsidian vault

私人 Git 儲存庫適合已經在使用版本控制的群組。典型流程如下：

1. 建立私人儲存庫，只加入想要共用的 vault 內容。上傳前請檢查附件、設定檔以及既有的 Git 歷史。
2. 邀請協作者加入儲存庫。
3. 每個人複製（clone）儲存庫，並在 Obsidian 中將本機資料夾作為 vault 開啟。
4. 編輯前先拉取（pull）最新變更，完成後提交（commit）並推送（push）。如有衝突，先解決再繼續。

[Obsidian Git 外掛](https://github.com/Vinzent03/obsidian-git/blob/master/docs/Start%20here.md)可以讓你在 Obsidian 內操作 Git。私人儲存庫會限制存取，但本身不提供端到端加密。如果你剛接觸 Git，可以閱讀我們的 [Obsidian Git 同步指南](/zh-tw/blog/obsidian-git-sync/)，了解工作流程及其取捨。

### 4. 透過雲端資料夾共用 vault

只要服務商能讓每位協作者在本機存取同一組檔案，就可以考慮共用資料夾：

1. 在雲端儲存空間中建立專用的 vault 資料夾，並授予協作者編輯權限。
2. 所有人將資料夾同步到自己的裝置，並保持檔案已下載到本機。
3. 在 Obsidian 中將本機資料夾作為 vault 開啟。
4. 加入更多資料前，先測試筆記和附件的變更能否雙向同步。

請先檢查行動裝置支援。在兩台筆記型電腦上可用的共用資料夾，在手機上的 Obsidian 中可能無法存取。[Obsidian 同步方法指南](https://obsidian.md/help/sync-notes)說明了各平台的限制。此 vault 只使用一個同步服務，避免更新互相衝突。

## 共用 vault：Obsidian Sync Plus 與 Synch Plus 比較

Obsidian Sync 是 Obsidian 內建的官方服務。Synch 透過社群外掛連接，並在 Plus 方案中提供以組織為單位的共用功能。兩者都支援對 vault 內容進行端到端加密。以功能比較，Obsidian Sync Plus 與 Synch Plus 更接近：兩者都提供一年的版本歷史，並支援比 Obsidian Standard 更大的附件。不過，它們的儲存配額和訂閱方式仍有差異。

| 項目 | Obsidian Sync Plus | Synch Plus |
|---|---|---|
| **訂閱方式** | 每位協作者都需要有效的 Sync 訂閱 | **一份訂閱最多包含 3 名成員，包括擁有者** |
| **端到端加密** | 可用於加密 vault | 包含 vault 內容加密 |
| **vault 密碼設定** | 協作者輸入 vault 的加密密碼 | **核准後，每位成員設定自己的 vault 密碼** |
| **加入方式** | 擁有者透過 Sync 設定邀請 | 先接受組織邀請，再完成加密存取核准 |
| **版本歷史** | 12 個月 | 1 年 |
| **包含的儲存空間** | 一個帳號下的所有 vault 合計 10 GB | **每個 vault 5 GB，3 個共 15 GB** |
| **最大檔案大小** | 200 MB | 100 MB |
| **同步 vault 數量** | 每個帳號 10 個 | 每個組織 3 個 |

有關要求和最新限制，請參閱 [Obsidian 共用 vault 指南](https://obsidian.md/help/sync/collaborate)、[Obsidian Sync 方案](https://obsidian.md/sync)和 [Synch 定價](https://synch.run/zh-tw/pricing)。

### 加密存取：共用密碼還是個人密碼

使用 Synch 時，**不必把自己的 vault 密碼傳給對方，也能邀請對方加入**。管理員透過協作者的驗證碼核准存取，因此不需要向整個群組分發共用密碼。

## 為日常協作整理共用 vault

無論選擇哪種方法，事先約定一些規則都會有幫助。

**將個人筆記與共用資料分開。** 專用的協作 vault 能明確區分哪些內容屬於群組。只放入你打算讓他人存取的資料，並考慮保留的歷史中是否包含私人內容。

**保持結構簡單。** 一篇入口筆記、一個專案資料夾、會議紀錄和參考資料通常就夠了。說明新筆記應該放在哪裡，讓成員不必重新整理整個 vault 就能參與。

**協調多人頻繁編輯的筆記。** 開會時指定一名記錄者，或為長文件分配不同章節。在把工作交給別人之前，等待同步完成。實用的編輯習慣可參考[預防 Obsidian 同步衝突指南](/zh-tw/blog/obsidian-sync-conflicts/)。

**將設定與內容分開考慮。** 即使筆記是共用的，佈景主題、快捷鍵和工作區偏好也可能因人而異。請檢查所選方法如何處理 `.obsidian` 設定資料夾。

**一個 vault 只使用一種同步方式，並另外備份。** Obsidian 不建議在同一 vault 上混用同步服務，因為可能引發衝突。[同步指南](https://obsidian.md/help/sync-notes)說明了相關注意事項。

## Obsidian vault 共用常見問題

### 可以免費共用 Obsidian vault 嗎？

使用 Git 或既有的共用儲存方案，可能不必專門訂閱同步服務就能協作。請檢查託管限制、裝置相容性以及每個人需要完成的設定。免費軟體也可能需要持續維護。

### 可以直接把 vault 資料夾傳給別人嗎？

可以，前提是對方需要的只是某個時間點的副本。請包含筆記所依賴的附件，並先移除私人資料。如果不設定同步或其他協作流程，之後的編輯不會在兩份副本之間傳遞。

### 不使用 Obsidian Sync 也能共用 vault 嗎？

可以。你可以使用 Synch、Git 或相容的雲端共用資料夾，不必支付 Obsidian Sync 訂閱費。如果選擇官方共用 vault 服務，每位協作者都需要有效的 Obsidian Sync 訂閱。

### 可以只共用 vault 中的一個資料夾嗎？

如需共同編輯，請建立一個獨立的 vault，放入群組需要的筆記和附件。複製後檢查連結：指向個人 vault 中某篇筆記的連結，並不會讓協作者取得該筆記的存取權限。

### 必須共用加密密碼嗎？

取決於服務。使用官方 Obsidian Sync 時，協作者連接加密 vault 需要輸入 vault 的加密密碼。使用 Synch 時，每位協作者在加密存取獲得核准後設定自己的 vault 密碼。

### 兩個人能同時編輯同一篇筆記嗎？

兩人可以編輯各自的本機副本，但重疊的變更可能造成衝突。不要預設本文介紹的共用方法支援即時協同編輯。如果同時寫作是核心需求，請評估明確支援該功能的工具。

### 有人退出群組時該怎麼辦？

透過所用服務移除對方的存取權限。撤銷權限不會刪除已下載的檔案，因此只應共用你願意讓對方保留副本的資料。

## 哪種服務適合你的群組？

如果所有人都已訂閱，或者你偏好官方整合功能，Obsidian Sync 是自然的選擇。

如果是兩三個人一起共用筆記，並希望由一個人管理方案、邀請其他成員，可以選擇 [Synch Plus](/zh-tw/pricing/)。

先用幾篇互相連結的筆記和一個附件試用所選方法。移轉共用專案之前，讓所有人連接、做些修改，並在實際使用的裝置上檢查結果。

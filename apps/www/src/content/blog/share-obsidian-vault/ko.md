**다른 사람과 Obsidian vault를 공유하려면** Obsidian Sync, Synch, 비공개 Git 저장소 또는 클라우드 공유 폴더를 사용할 수 있습니다. 각자 Obsidian에서 로컬 사본을 열면 선택한 방식으로 사본 사이에 변경 사항이 전달됩니다. vault 폴더를 한 번 보내는 것은 그 시점의 사본을 전달하는 일일 뿐, 이후 노트를 계속 동기화해 주지는 않습니다.

스터디 그룹, 공동 연구 자료실, 팀 지식 베이스를 만들 때는 먼저 구성원의 참여 방식과 사용할 기기를 정하세요. 이 글에서는 네 가지 협업 방법을 소개하고, Obsidian Sync와 Synch의 설정 절차 및 저장 공간, 암호화된 접근 권한, 버전 이력을 비교합니다.

![연결된 노트 모음을 공유하는 노트북 세 대. 각 기기에 있는 Obsidian vault의 로컬 사본을 나타냅니다.](./shared-vault-collaboration.webp)

## 어떤 Obsidian 공유 방식을 선택해야 할까요?

| 방법 | 이런 경우에 적합합니다 | 주요 조건 또는 한계 |
|---|---|---|
| **Obsidian Sync** | 공식 통합 기능을 원하거나 모두 이미 구독 중일 때 | 참여자마다 Sync 구독 필요 |
| **Synch Plus** | 두세 명이 하나의 그룹 구독을 쓰고 싶을 때 | 조직 가입 후 암호화된 접근 권한 승인 필요 |
| **비공개 Git 저장소** | 모두 버전 관리에 익숙할 때 | 참여자가 commit, pull, push, 병합 충돌을 관리해야 함 |
| **클라우드 공유 폴더** | 모든 참여자의 기기에서 로컬 공유 폴더를 지원할 때 | 모바일 접근과 충돌 처리 방식은 제공업체마다 다름 |

**Obsidian 노트를 읽기 전용으로 전달**하기만 하면 된다면 Markdown 파일을 보내거나 PDF로 내보내세요.

**vault 공유는 실시간 공동 편집과 다릅니다.** 동기화는 로컬 사본 사이에 저장된 변경 사항을 전달합니다. 다른 사람의 커서나 키 입력 하나하나까지 보여 주는 것은 아닙니다. 같은 노트를 작업할 때는 편집 순서를 조율하세요.

## 다른 사람과 Obsidian vault를 공유하는 방법

먼저 vault를 백업한 뒤 아래 방법 중 하나를 선택하세요. 새 그룹이라면 전용 vault를 만들어 개인 노트와 모두가 접근할 자료를 분리하는 것이 좋습니다.

### 1. Obsidian Sync로 vault 공유하기

Obsidian Sync의 원격 vault에 연결된 로컬 vault에서 시작합니다. 참여자마다 활성 Sync 구독이 있어야 합니다.

초대하는 방법은 다음과 같습니다. 메뉴 이름은 영어 UI 기준입니다.

1. **Settings → Sync**를 엽니다.
2. **Remote vault** 옆의 **Manage**를 선택합니다.
3. 공유할 vault를 찾아 **Manage sharing**을 선택합니다.
4. **Invite user**에 상대방의 이메일 주소를 입력합니다.
5. **Add**를 선택합니다.

초대받은 사람은 로컬 vault를 공유 원격 vault에 연결합니다. 종단 간 암호화된 vault라면 신뢰할 수 있는 경로로 암호화 비밀번호를 전달하세요. 자세한 내용은 [공식 공유 vault 안내](https://obsidian.md/help/sync/collaborate)를 참고하세요.

참여자는 vault 내용을 편집할 수 있지만, 다른 사람을 초대할 수 있는 사람은 소유자뿐입니다. Obsidian Sync는 세분화된 권한이나 실시간 공동 편집을 제공하지 않습니다.

### 2. Synch로 vault 공유하기

vault가 Synch에 연결되어 있고 조직이 Plus 요금제를 사용 중인 상태에서 진행합니다.

1. **참여자를 초대합니다.** **Vault 공유 → 조직 관리**를 열고 이메일 초대를 보냅니다.
2. **상대방이 접근 권한을 요청합니다.** 초대를 수락한 뒤 빈 Obsidian vault를 열고 Synch에 로그인합니다. **Vault 연결 → 공유받은 vault**에서 공유할 vault를 선택합니다.
3. **승인하고 연결합니다.** 별도의 신뢰할 수 있는 경로로 상대방의 전체 접근 코드를 확인하고 **Vault 공유**에서 승인합니다. 상대방은 요청했던 기기에서 자신의 vault 비밀번호를 설정하고 연결을 마칩니다.

승인하면 보관 중인 이력에도 접근할 수 있습니다. 초대받은 구성원에게는 Synch 계정이 필요하지만 별도의 유료 요금제는 필요하지 않습니다.

### 3. Git으로 Obsidian vault 공유하기

비공개 Git 저장소는 이미 버전 관리를 사용하는 그룹에 적합합니다. 일반적인 흐름은 다음과 같습니다.

1. 비공개 저장소를 만들고 공유할 vault 내용만 추가합니다. 업로드 전에 첨부 파일, 설정 파일, 기존 Git 이력을 확인하세요.
2. 저장소에 참여자를 초대합니다.
3. 각자 저장소를 복제(clone)한 뒤 로컬 폴더를 Obsidian vault로 엽니다.
4. 편집 전에 최신 변경 사항을 pull하고 작업 후 commit과 push를 합니다. 충돌이 생기면 해결한 뒤 계속하세요.

[Obsidian Git 플러그인](https://github.com/Vinzent03/obsidian-git/blob/master/docs/Start%20here.md)을 사용하면 Obsidian 안에서 Git 작업을 할 수 있습니다. 비공개 저장소는 접근을 제한하지만 그 자체로 종단 간 암호화를 제공하지는 않습니다. Git이 처음이라면 [Obsidian Git 동기화 가이드](/ko/blog/obsidian-git-sync/)에서 작업 흐름과 장단점을 확인하세요.

### 4. 클라우드 폴더로 vault 공유하기

클라우드 서비스가 모든 참여자에게 같은 파일을 로컬로 제공한다면 공유 폴더를 사용할 수 있습니다.

1. 클라우드 저장소에 전용 vault 폴더를 만들고 참여자에게 편집 권한을 부여합니다.
2. 모두 각자의 기기에 폴더를 동기화하고 파일이 다운로드된 상태를 유지합니다.
3. 로컬 폴더를 Obsidian vault로 엽니다.
4. 더 많은 자료를 추가하기 전에 노트와 첨부 파일의 변경 사항이 양방향으로 전달되는지 테스트합니다.

모바일 지원부터 확인하세요. 노트북 두 대에서 잘 작동하는 공유 폴더라도 휴대폰의 Obsidian에서는 접근하지 못할 수 있습니다. 플랫폼별 한계는 [Obsidian 동기화 방법 안내](https://obsidian.md/help/sync-notes)에서 확인할 수 있습니다. 업데이트가 서로 충돌하지 않도록 이 vault에는 동기화 서비스를 하나만 사용하세요.

## 공유 vault를 위한 Obsidian Sync Plus와 Synch Plus 비교

Obsidian Sync는 Obsidian에 내장된 공식 서비스입니다. Synch는 커뮤니티 플러그인으로 연결하며 Plus 요금제에서 조직 단위 공유를 제공합니다. 두 서비스 모두 vault 내용의 종단 간 암호화를 지원합니다. Synch Plus와 기능을 비교하기에는 Obsidian Sync Plus가 더 가깝습니다. 둘 다 1년의 버전 이력을 제공하고 Obsidian Standard보다 큰 첨부 파일을 지원합니다. 다만 저장 공간과 구독 방식에는 차이가 있습니다.

| 항목 | Obsidian Sync Plus | Synch Plus |
|---|---|---|
| **구독 방식** | 참여자마다 활성 Sync 구독 필요 | **구독 하나에 소유자 포함 최대 3명** |
| **종단 간 암호화** | 암호화된 vault에서 사용 가능 | vault 내용에 포함 |
| **vault 비밀번호 설정** | 참여자가 vault의 암호화 비밀번호 입력 | **승인 후 각자 자신의 vault 비밀번호 설정** |
| **참여 방법** | 소유자가 Sync 설정에서 초대 | 조직 초대 후 암호화된 접근 권한 승인 |
| **버전 이력** | 12개월 | 1년 |
| **기본 저장 공간** | 한 계정의 모든 vault를 합해 10 GB | **vault당 5 GB, 3개 합계 15 GB** |
| **최대 파일 크기** | 200 MB | 100 MB |
| **동기화 vault 수** | 계정당 10개 | 조직당 3개 |

요구 사항과 최신 한도는 [Obsidian 공유 vault 안내](https://obsidian.md/help/sync/collaborate), [Obsidian Sync 요금제](https://obsidian.md/sync), [Synch 요금제](https://synch.run/ko/pricing)를 참고하세요.

### 암호화된 접근 권한: 공용 비밀번호와 개인별 비밀번호

Synch에서는 **자신의 vault 비밀번호를 전달하지 않고 다른 사람을 초대할 수 있습니다**. 관리자가 참여자의 인증 코드로 접근 권한을 승인하므로 그룹에 공용 비밀번호를 배포할 필요가 없습니다.

![잠긴 공유 폴더에 연결된 세 구성원의 개별 자격 증명. 개인별 비밀번호로 암호화된 접근 권한을 설정하는 모습을 나타냅니다.](./individual-vault-passwords.webp)

## 일상적인 협업을 위한 공유 vault 정리

어떤 방법을 선택하든 몇 가지 약속을 정해 두면 도움이 됩니다.

**개인 노트와 공유 자료를 분리하세요.** 협업 전용 vault를 쓰면 그룹의 자료가 무엇인지 명확해집니다. 다른 사람에게 공개할 자료만 넣고, 보관 중인 이력에 개인 정보가 남아 있는지도 고려하세요.

**구조를 단순하게 유지하세요.** 시작 노트, 프로젝트 폴더, 회의록, 참고 자료 정도면 충분한 경우가 많습니다. 새 노트를 어디에 둘지 안내하면 전체 vault를 재정리하지 않고도 참여할 수 있습니다.

**여러 사람이 작업하는 노트는 조율하세요.** 회의 중에는 기록 담당자를 한 명 정하거나 긴 문서의 구역을 나누세요. 다른 사람에게 작업을 넘기기 전에 동기화가 끝날 때까지 기다리세요. 실용적인 편집 습관은 [Obsidian 동기화 충돌 예방 가이드](/ko/blog/obsidian-sync-conflicts/)를 참고하세요.

**설정은 내용과 별도로 검토하세요.** 노트를 공유하더라도 테마, 단축키, 작업 공간 설정은 개인마다 다를 수 있습니다. 선택한 방식이 `.obsidian` 설정 폴더를 어떻게 처리하는지 확인하세요.

**vault에는 동기화 방식 하나만 사용하고 별도로 백업하세요.** Obsidian은 같은 vault에 여러 동기화 서비스를 함께 사용하면 충돌이 발생할 수 있어 권장하지 않습니다. 관련 주의 사항은 [동기화 안내](https://obsidian.md/help/sync-notes)에 설명되어 있습니다.

## Obsidian vault 공유 FAQ

### Obsidian vault를 무료로 공유할 수 있나요?

Git이나 이미 사용 중인 공유 저장소 요금제를 이용하면 별도 동기화 구독 없이 협업할 수도 있습니다. 호스팅 한도, 기기 호환성, 각자 필요한 설정을 확인하세요. 무료 소프트웨어라도 지속적인 관리가 필요할 수 있습니다.

### vault 폴더를 그냥 보내도 되나요?

특정 시점의 사본이 필요하다면 가능합니다. 노트에서 사용하는 첨부 파일을 포함하고 개인 자료는 먼저 제거하세요. 동기화나 다른 협업 흐름을 설정하지 않으면 이후 수정 내용은 두 사본 사이에 전달되지 않습니다.

### Obsidian Sync 없이도 vault를 공유할 수 있나요?

네. Obsidian Sync를 구독하지 않아도 Synch, Git, 호환되는 클라우드 공유 폴더를 사용할 수 있습니다. 공식 공유 vault 서비스를 선택한다면 모든 참여자에게 활성 Obsidian Sync 구독이 필요합니다.

### vault 안의 폴더 하나만 공유할 수 있나요?

함께 편집하려면 그룹에 필요한 노트와 첨부 파일을 담은 별도 vault를 만드세요. 복사한 뒤에는 링크를 확인하세요. 개인 vault에 남아 있는 노트를 가리키는 링크만으로는 참여자가 그 노트에 접근할 수 없습니다.

### 암호화 비밀번호를 공유해야 하나요?

서비스에 따라 다릅니다. 공식 Obsidian Sync에서는 참여자가 암호화된 vault에 연결할 때 vault 암호화 비밀번호를 사용합니다. Synch에서는 암호화된 접근 권한이 승인된 뒤 각자 자신의 vault 비밀번호를 설정합니다.

### 두 사람이 같은 노트를 동시에 편집할 수 있나요?

각자의 로컬 사본을 편집할 수는 있지만 변경이 겹치면 충돌이 생길 수 있습니다. 이 글에서 다루는 공유 방식이 실시간 공동 편집까지 제공한다고 가정해서는 안 됩니다. 동시 작성이 작업의 핵심이라면 이를 명시적으로 지원하는 도구를 검토하세요.

### 누군가 그룹을 떠나면 어떻게 하나요?

사용 중인 서비스에서 해당 구성원의 접근 권한을 제거하세요. 권한을 취소해도 이미 다운로드한 파일은 지워지지 않으므로 상대방이 사본을 보관해도 괜찮은 자료만 공유하세요.

## 우리 그룹에는 어떤 서비스가 맞을까요?

모두 이미 구독 중이거나 공식 통합 기능을 선호한다면 Obsidian Sync가 자연스러운 선택입니다.

두세 명이 함께 노트를 공유하면서 한 사람이 요금제를 관리하고 나머지를 초대하고 싶다면 [Synch Plus](/ko/pricing/)를 선택하세요.

먼저 링크로 연결된 노트 몇 개와 첨부 파일로 선택한 방식을 시험해 보세요. 공동 프로젝트를 옮기기 전에 모두 연결하고 수정해 본 뒤, 실제로 사용하는 기기에서 결과를 확인하세요.
